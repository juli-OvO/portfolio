Bio

Julianne Jin
Computational Designer · RISD

I'm a computational designer working on interaction, systems, and tool-building. Most of my projects combine web technologies, generative systems, and physical computing.

I like building things I can test early: coded prototypes, working circuits, small tools that make the next step easier. I'm most interested in systems that change as you use them, and in keeping them clear enough to actually be used.
