## Description

A redesign for Heads Up, a student-led nonprofit for healthier screen habits. My direction was chosen from three, and I built it in Webflow along with a small helper tool for the rebuild.

### Helper tool

A small tool I built for the Webflow rebuild. Click any element on the old site to read its class, spacing, and type, so each piece can be rebuilt to match.

5. `web/webflow-helper.jpg` — Click an element to inspect its class, spacing, and type.

### Design guide

One system across every page: stickers that open sections, pills for labels, a highlighter for key words, handwritten notes, and numbered rules.
